Welcome to etoh_tower_menu!

First of all, the first complete version of the application is on the branch console_branch, so please change the branch before downloading the application.

To run this file, you need to download the project as a .ZIP file(or clone it, if you want), and then the next steps depend if you have PyCharm or not:
1. If you have PyCharm, just open the project in PyCharm(File -> Open and then select the folder etoh_tower_menu), and then go to main.py and run the program.
2. If you don't have PyCharm, you will need to use the Command Prompt to run thee program. The steps are:
- first, open the command prompt and go to the etoh_tower_menu file, using cd directory to change directories, and if you need to change the disk enter the letter of the disk followed by a colon(for example D:, E:);
- once you are in the etoh_tower_menu folder, you need to run the command <path>\venv\Scripts\activate.bat, where path is the path to etoh_tower_menu(so for example D:\etoh_tower_menu\venv\Scripts\activate.bat). This activates the packages needed to run the application;
- now you need to enter .\main.py in the terminal, and you will be able to use the application.

That is how you install the application.
